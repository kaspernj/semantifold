Task 040 adds immutable registry-driven developer check plans, a target-neutral owned process runner, and strict `semantifold build --check` support. Java now owns an exact canonical `javac` plan that compiles every staged `.java` artifact into the generation-scoped build subtree; generated source and hashed class outputs become active together only after all checks succeed. Every checked invocation owns a fresh immutable candidate and reruns its checks, while generation-only same-ID verification remains deterministic. Compiler discovery, plan, launch, timeout, cancellation through the atomic pointer-commit boundary, signal, output-limit, non-zero, and publication failures retain the previous active generation; human and NDJSON reporting preserve nested tool/compiler evidence without executing generated code.
