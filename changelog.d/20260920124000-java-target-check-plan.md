Task 040 adds immutable registry-driven developer check plans, a target-neutral owned process runner, and strict `semantifold build --check` support. Java now owns an exact canonical `javac` plan that compiles every staged `.java` artifact into the generation-scoped build subtree; generated source and hashed class outputs become active together only after all checks succeed. Compiler discovery, plan, launch, timeout, cancellation through the atomic pointer-commit boundary, signal, output-limit, non-zero, and publication failures retain the previous active generation, while human and NDJSON reporting preserve bounded compiler evidence without executing generated code.
