Task 005 adds arbitrary required positional function signatures, deterministic direct-call resolution, recursion, and explicit scalar or void returns across PHP, Ruby, JavaScript/JSDoc, TypeScript, and Java. Calls now receive exact declaration/signature bindings, void calls are permitted only as statements, and malformed or unsupported source and semantic forms fail before target artifacts are emitted. Registered Python, C#, C, C++, Rust, Swift, Kotlin/JVM, Go, and browser Wasm targets retain their Tasks 001–004 function profile and report Task 005 shapes as unsupported capabilities.
